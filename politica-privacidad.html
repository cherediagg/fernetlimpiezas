2. Datos que recopilamos y finalidad del tratamiento

Este sitio web es de carácter eminentemente informativo sobre los servicios de limpieza ofrecidos por Fernet Limpiezas.

Únicamente se recopilan datos personales en los siguientes supuestos:

  • Formularios de contacto o presupuestos: Cuando el usuario facilita datos voluntariamente (nombre, teléfono, email, tipo de servicio y consulta) con el fin exclusivo de atender la solicitud de información o propuesta económica enviada.
  • Datos de analítica web (Google Analytics): Se recogen datos estadísticos anónimos y agregados sobre las visitas al sitio web (páginas vistas, tiempo de estancia, navegador utilizado) con la finalidad de evaluar y mejorar la experiencia de navegación del usuario.

3. Legitimación para el tratamiento

La base legal para el tratamiento de sus datos es el propio consentimiento expreso manifestado al enviar una solicitud mediante nuestros formularios de contacto, o bien el interés legítimo de Fernet Limpiezas para optimizar el sitio web mediante métricas de uso anónimas.


4. Conservación de los datos

Los datos facilitados mediante el formulario de contacto se conservarán durante el tiempo estrictamente necesario para responder a la consulta planteada o para la gestión de la relación comercial correspondiente, de acuerdo con los plazos legales aplicables.


5. Cesión y destinatarios de los datos

Fernet Limpiezas no venderá, alquilará ni cederá datos personales a terceros, salvo obligación legal.

Para la recogida de métricas y estadísticas de uso, el sitio web hace uso de Google Analytics, un servicio prestado por Google LLC que procesa datos de acuerdo con los estándares de privacidad adecuados.


6. Derechos de los usuarios

El usuario tiene derecho a ejercitar en cualquier momento los siguientes derechos en relación con sus datos personales:

  • Acceso a sus datos personales.
  • Rectificación de datos inexactos o incompletos.
  • Supresión de sus datos cuando ya no sean necesarios para los fines que fueron recogidos.
  • Oposición o limitación del tratamiento.
  • Portabilidad de los datos.

Para ejercitar cualquiera de estos derechos, el usuario puede enviar una solicitud por escrito adjuntando copia de su documento de identidad a la dirección postal en Badalona o al correo electrónico info@limpiezasfernet.com.
